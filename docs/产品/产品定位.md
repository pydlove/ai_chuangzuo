# 产品定位

## 一句话定位

爱创作是面向普通人的“自媒体运营流水线”，把“不知道写什么、不知道怎么发、不知道怎么变现”变成一套可执行的 AI 辅助流程。

## 核心目标

让有意愿做自媒体但缺乏运营能力的人，能够：

1. 快速找到适合自己的平台、赛道和人设；
2. 持续获得差异化选题和角度；
3. 生成有个人印记、不易同质化的内容；
4. 知道怎么发布和运营；
5. 最终形成稳定的副业收入或个人 IP。

## 目标用户

核心用户不是专业自媒体人，而是想靠内容获客、变现或建立影响力的普通人。

典型画像：

| 类型 | 描述 |
|---|---|
| 副业增收型 | 有主业，想利用碎片时间做自媒体赚额外收入 |
| 专业转型型 | 有垂直经验（职场、技术、育儿、金融等），想输出内容打造个人 IP |
| 小生意引流型 | 有产品/服务，想通过内容获取客户 |
| 经验分享型 | 有某方面经历，想记录并影响同频人群 |

共性：有意愿、有时间、有素材，但缺少自媒体选题、写作、运营能力。

## 用户痛点

1. **不知道写什么**：打开编辑器没有方向，选题靠拍脑袋。
2. **不知道平台怎么玩**：不了解不同平台的内容形态、推荐逻辑和最佳发布时间。
3. **写不出爆款**：不会写标题、开头、结构、钩子。
4. **同质化被限流**：追热门导致内容和别人雷同，账号被判定低创作度。
5. **变现路径不清**：有流量但不知道怎么赚钱。
6. **难以持续**：没有固定内容节奏，发几篇就放弃。

## 产品价值主张

> 不是帮你生成一篇文章，而是帮你建立一套可持续的自媒体运营方案。

通过 AI + 平台数据 + 运营策略，把复杂的自媒体工作拆成固定流程：

- 首次进入：自媒体方案 → 选平台 → 定目标 → 选赛道 → 做人设
- 日常使用：工作台 → 推荐选题 → 差异化角度 → 注入个人素材 → 生成文章 → 发布策略 → 运营复盘

## 核心差异化

| 维度 | 普通 AI 写作工具 | 爱创作 |
|---|---|---|
| 起点 | 空白编辑器 | 先定位，再创作 |
| 推荐逻辑 | 追热点 | 基于低粉高赞数据 + 蓝海细分赛道 |
| 内容来源 | AI 生成大路货 | 强制注入用户个人素材，降低同质化 |
| 后续运营 | 只生成文章 | 提供发布时间、标题、冷启动、复盘建议 |
| 用户成长 | 一次性使用 | 持续推荐、迭代定位 |

## 使用场景

- 刚想做自媒体，完全不知道从哪里开始；
- 做了一段时间但账号起不来，想重新定位；
- 有垂直经验，想系统化输出内容变现；
- 想批量运营多平台内容，但不知道各平台差异。
