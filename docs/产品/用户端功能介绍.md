# 爱创作 — 用户端功能介绍

> 本文档面向产品、运营与开发团队，系统梳理爱创作用户端（面向普通创作者的前台）全部功能模块、使用场景与核心规则。
> 最后更新：2026-08-25

---

## 一、产品概述

### 1.1 一句话定位

爱创作是面向普通人的"自媒体运营流水线"，把"不知道写什么、不知道怎么发、不知道怎么变现"变成一套可执行的 AI 辅助流程。

### 1.2 核心价值

| 维度 | 传统 AI 写作工具 | 爱创作 |
|---|---|---|
| 起点 | 空白编辑器 | 先定位，再创作 |
| 推荐逻辑 | 追热点 | 基于低粉高赞数据 + 蓝海细分赛道 |
| 内容来源 | AI 生成大路货 | 强制注入用户个人素材，降低同质化 |
| 后续运营 | 只生成文章 | 提供发布时间、标题、冷启动、复盘建议 |
| 用户成长 | 一次性使用 | 持续推荐、迭代定位 |

### 1.3 目标用户

- 副业增收型：有主业，想利用碎片时间做自媒体赚额外收入
- 专业转型型：有垂直经验，想输出内容打造个人 IP
- 小生意引流型：有产品/服务，想通过内容获取客户
- 经验分享型：有某方面经历，想记录并影响同频人群

### 1.4 核心使用路径

```
首次进入：制定自媒体方案 → 选平台 → 定目标 → 选赛道 → 做人设
日常使用：工作台 → 推荐选题 → 差异化角度 → 注入个人素材 → 生成文章 → 发布策略 → 运营复盘
```

## 二、营销与获客页（未登录/访客态）

### 2.1 首页（`/`）

面向未登录访客的营销落地页，叙事主线：激情抓眼 → 理性证据 → 激情收尾。

主要板块：

- **Hero 区**：主标题「会增值的自媒体账号，从第一篇文章开始」，强调 AI 写作 + 多平台变现 + 账号长期增值
- **数据区**：累计为创作者带来收益、累计注册账号、覆盖变现平台数、平均成稿时间
- **特色功能 6 张卡**：
  - 3 分钟成稿
  - 一稿多发跨平台
  - 爆款结构
  - 导出即发布
  - 持续变现（创作币、返利、排行榜奖金、外部收入申报）
  - 账号资产复利
- **收益玩法矩阵**：4 种变现路径（创作币奖励、邀请返利、排行榜奖金、自媒体收入申报）
- **三步起号**：注册账号 → 输入主题 → AI 产出
- **终 CTA**：引导立即开始创作或查看玩法指南
- **统一 Footer**：版权信息、备案号、关于我们入口

### 2.2 玩法指南（`/guide`）

帮助用户理解如何使用爱创作进行自媒体运营，包括平台选择、内容创作、发布策略和变现路径。

### 2.3 会员定价页（`/pricing`）

展示爱创作会员套餐与权益对比，支持按周期（月/季/年）切换价格，支持创作币抵扣、优惠券抵扣，新人折扣等。

套餐：

- 基础版（Basic）
- 专业版（Pro）
- 旗舰版（Flagship）

### 2.4 创作学院（`/learn`）

文档式浏览页，按分类树展示平台运营课程与文章，支持 Markdown / 富文本渲染，PC 端左侧分类树 + 右侧内容，移动端底部抽屉切换分类。

内容由管理端「创作学院」菜单维护。

### 2.5 移动端首页（`/m`）

适配移动设备的营销首页，内容与 PC 首页一致，采用移动优先的卡片式布局与抽屉导航。

- AI 顾问「小爱」欢迎语
- 个人信息（昵称、会员等级、联系方式、邀请码）
- 账户余额（创作币）与提现入口

### 5.2 运营方案卡

展示当前用户的自媒体运营方案：

- 主攻平台

### 5.3 开始今日创作

提供两种创作入口：

- **按小爱推荐的方式创作**：基于运营方案，AI 推荐选题 → 观点角度 → 字数 → 提示词 → 模板，最终提交真实生成任务
- **自由创作**：直接进入创作页，由用户自主输入主题与配置

### 5.4 快捷操作

- 账号名检测
- 约稿中心
- 提示词市场
- 收益排行榜
- 热搜榜
- 创作学院
- 我的作品
- 我的提示词
- 我的账户
- 我的权益
- 我的优惠券
- 帮助文档

### 5.5 生成记录

展示最近生成任务列表，包含标题、平台、状态、进度、创建时间，支持跳转到预览/继续生成。

### 5.6 本周数据

展示本周创作数据（生成文章数、字数、平台分布等）。

## 六、自媒体方案制定（`/console/onboarding`）

AI 驱动的 5 步向导，帮助用户从 0 到 1 确定自媒体定位。

### 6.1 问卷采集

收集用户画像：

- 主业/副业/想转主业/不明确
- 每周投入时间
- 期望月收入
- 可接受不盈利周期
- 倾向内容形式
- 目标受众
- 身份标签
- 是否愿意出镜/做视频
- 补充说明

### 6.2 五步制定流程

1. **AI 推荐平台**：基于问卷推荐最合适平台（小红书、公众号、今日头条、百家号、知乎、抖音、B站等）
2. **定目标**：AI 推荐 3-5 个变现方向，用户选择核心目标
3. **选赛道**：AI 推荐 3 个细分赛道，展示目标人群、变现方式、同质化风险、参考案例数
4. **做人设**：AI 推荐 3-4 个人设定位，并给出默认内容支柱比例
5. **出方案**：确认平台、目标、赛道、人设、内容支柱，保存到后端

### 6.3 方案应用

- 保存后跳转工作台
- 工作台展示运营方案
- 「按小爱推荐的方式创作」基于方案生成选题

## 七、创作流程

### 7.1 创作页（`/console/create`）

双模式设计，共享同一份创作配置：

#### 7.1.1 对话引导模式（默认）

- 居中聊天流，AI 一步步引导完成创作配置
- 固定 4 步：主题 → 平台 → 风格 → 确认
- 每步提供快捷胶囊 + 效果预览卡，两段式确认
- 确认后展示汇总卡片，点击「开始生成」
- 生成中显示进度卡片，完成后显示结果卡片

#### 7.1.2 极简模式

- 居中一体化输入卡片
- 标题 + 补充要求合并输入
- 平台、字数、风格、模板 4 个配置胶囊平铺
- 保存草稿/草稿箱 + 生成文章按钮
- 右侧队列抽屉，点生成后自动滑出

### 7.2 创作配置

#### 平台选择

支持 7 大平台：公众号、小红书、今日头条、百家号、知乎、抖音、B站、通用。

每个平台自动带出推荐字数、默认模板、平台特性（如小红书短段落多 emoji、自动带话题标签）。

#### 字数设置

支持按平台、场景、等级或自定义 1-3000 字选择。

#### 风格选择

- 系统预设风格
- 我的风格
- 学习的风格
- 风格市场风格

#### 模板选择

30+ 导出模板，按平台分组（公众号、小红书、头条、百家号、知乎、抖音、通用）。

#### 提示词（Prompt）

支持用户补充创作要求、语气、案例、重点等。

### 7.3 按小爱推荐的方式创作弹框

基于运营方案的 AI 推荐创作流程：

1. **选题**：AI 推荐 6 个今日创作选题，标注同质化风险、参考案例数、推荐切入角度
2. **观点**：选中选题后，AI 生成 7 个差异化观点/切入角度，用户选 1-3 个
3. **字数**：选择文章字数
4. **提示词**：选择/输入创作提示词
5. **模板**：选择导出模板
6. **生成**：调用真实生成任务接口，成功后清除会话

### 7.4 生成队列

- 提交生成任务后进入队列
- 任务状态：排队中 → 生成中 → 已完成 / 失败
- 支持查看进度、取消任务、重新生成
- 历史任务在「我的作品」中查看

### 7.5 预览与导出（`/console/preview/:id`）

- 文章预览：按所选平台模板渲染
- 在线编辑：支持修改标题、正文、段落
- 标题优化：AI 推荐多个爆款标题
- 导出 Word：下载 .docx 文件
- 复制正文：一键复制
- 生成卡片：基于文章内容生成分享卡片

### 7.6 文章手动编辑

支持在预览页对生成结果进行手动修改：

- 富文本编辑器
- 标题修改
- 段落增删
- 图片插入
- 格式调整

## 十、变现与激励

### 10.1 创作币体系

创作币是爱创作平台内的虚拟货币，1 创作币 = 1 元人民币。

获取途径：

- 完成任务/活动
- 邀请好友
- 上榜奖励
- 风格/提示词被使用
- 约稿任务获奖
- 抽奖中奖
- 兑换码兑换

使用场景：

- 抵扣会员购买
- 提现到支付宝（满 100 创作币）

### 10.2 约稿中心（`/console/commission`）

用户可发布或承接稿件征集任务，以创作币结算。

核心流程：

1. 发布者发布约稿任务（标题、要求、字数、奖励、截止时间）
2. 奖励即时从发布者余额冻结
3. 投稿人从自己已生成的作品中选择一篇投递
4. 同一用户同一任务仅可投递一次
5. 截止前发布者选择一名获胜者
6. 平台抽成 10%，获奖者获得奖励 × 90%
7. 截止 + 24 小时宽限期未选则任务流局，奖励退还

页面：

- 任务列表（全部任务 / 我发布的 / 我投稿的）
- 发布约稿
- 任务详情（发布者视角 / 投稿人视角 / 旁观者视角）

### 10.3 邀请有礼（`/console/invite`）

长期拉新激励功能：

- 邀请链接 / 邀请码 / 邀请海报
- 被邀请人注册并完成邮箱验证后双方获得创作币
- 被邀请人购买会员后邀请人获得返利（首单 10%，后续 5%）
- 阶梯奖励：累计邀请 3 人 +30 币，5 人 +50 币，之后每多 1 人 +20 币
- 创作币满 100 可提现到支付宝

### 10.4 收益排行榜（`/console/leaderboard`）

两块榜单：

- **创作币榜**：按自然月统计平台用户获得的创作币收益，TOP10 各奖 100 创作币
- **自媒体收入榜**：月度榜 + 年度榜，用户可申报自己在公众号、小红书、抖音等平台的真实收入，审核通过后计入榜单

### 10.5 幸运抽奖（`/console/lottery`）

运营抽奖活动：

- 每轮活动每人免费抽奖次数
- 邀请新用户注册可获额外抽奖次数
- 奖项：创作币、会员天数/周期、订阅折扣券、谢谢回顾
- 中奖展示墙
- 兑换码兑换奖励

### 10.6 优惠券（`/console/coupons`）

- 查看我的优惠券
- 券类型：折扣券、立减券
- 适用套餐/周期
- 下单时选择使用

### 10.7 兑换码

- 控制台顶部入口
- 输入兑换码兑换创作币或会员天数
- 支持活动发放的兑换码

### 10.8 我的账户（`/console/earnings`）

- 账户余额（创作币）
- 收益明细（类型、金额、时间、来源）
- 提现申请
- 提现记录

### 10.9 提现

- 满 100 创作币可申请提现
- 填写提现金额、支付宝账号、真实姓名
- 提交后待运营审核
- 审核通过后打款并扣减余额

## 十二、会员与权益

### 12.1 会员套餐
